# 楚车知识管理

## 登录

首次启动按[后端启动说明](backend.md#从仓库启动)生成本机配置。打开 `http://127.0.0.1:8780/admin`，把 `.local/backend.json` 中 `operators` 下对应操作员的值填入「操作员凭据」。如需使用组内交接说明里的统一凭据，把对应值填进本机的 `operators.local-operator`，再重启后端。登录后可通过浏览器的「下次自动填充」保存凭据。

## AI 导入的 API Key

在项目根目录创建 `.local/ai.json`，把自己的 DeepSeek API Key 填到 `generation_key`。该文件位于 Git 忽略的本机目录。

```json
{
  "generation_key": "",
  "generation_model": "deepseek-flash"
}
```

也可在启动后端的同一个 PowerShell 窗口设置环境变量，环境变量优先于配置文件。

```powershell
$env:DEEPSEEK_API_KEY = "<你的 DeepSeek API Key>"
```

## 图谱编辑

搜索实体或选择图谱节点。右侧显示属性、关系、出处和当前状态。可直接创建实体、事实及关系；点「图上连线」后再选目标节点，可预填关系两端。资料记载可以链接已有证据，也可以粘贴新原文。删除操作沿用后端引用完整性检查，丢弃的记录可在回收站恢复。

默认打开「网络图」的知识层（ABox），也可切换到「分区图」。点「显示本体层」可在同一画布上显示两层。水平虚线上方的本体层（TBox）展示类型与允许的关系，下方展示实体和事实。点上方类型可查属性定义、关系两端和约束；点下方实体会高亮它所属的类型，并显示两者之间的归属线。

拖拽平移、滚轮缩放和「适应画布」同时作用于两层及分界线。知识层点选节点会突出相邻关系，「当前邻域」展示该实体和它的直接连线。知识层默认选择「战车知识」，主要展示车体、部件、标本、材质和属性；教学方案、导航和模型记录可在「全部记录」中维护。

点击「存入知识库」后，改动立即可在管理图谱查看。通过「待发布」单独审核发布；发布事实时会一并列出并确认它所需的待发布主体、目标和所属对象。更新已公开的实体或事实会将本次内容转回待发布，再次发布后才重新开放。上传来源的整份文本只在内部提供，公开端展示与已发布事实关联的原文摘录和行号。

本机已有的候选预览沿用原展示规则。管理端新建、变更或恢复的内容在候选预览、正式图谱及公开问答中均等待发布。正式展览使用 `confirmed_only` 配置。

## 文本导入

1. 上传 UTF-8 的 `.md` 或 `.txt`，单次不超过 80,000 字符。
2. DeepSeek 接收上传文本和当前有效图谱的全部实体、事实及支持证据。历史、回收站与以往上传材料的完整文件保留在本地。
3. 审核页展示新增、重复、可能冲突、相近记录、待确认以及无关内容。引文由后端从上传文本定位。后端比较同一对象的事实，尺寸会换算单位后比较；语义相近或冲突提示需要人工判断。
4. 可查看图上预览或编辑建议。编辑后调用后端重新检查。重复事实可以补证，可能冲突的值经明确确认可作为另一来源的记录入库。
5. 勾选建议入库，再到「待发布」确认上线。提交时再次校验当前图谱修订、证据和关系约束。提交期间图谱发生变化时，重新核对后再提交。

管理员接口以 `/api/v1/internal/admin/` 为前缀。`state` 提供编辑所需的当前知识和本体；`imports/analyze`、`imports/check`、`imports/commit` 分别处理抽取、重新检查及确认入库。直接编辑和发布复用现有[变更集接口](backend.md#增量维护)。
