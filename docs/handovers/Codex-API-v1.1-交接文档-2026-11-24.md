# 数据库与API v1.1阶段性交接

交付日期：2026-11-24。程序接口v1.1.0，知识数据v0.11、本体0.7.0、数据契约0.4.0。此次更新程序和接口，未改动知识发行文件或自动确认候选知识。

## 交付内容

- Neo4j Community持久化、约束／索引及官方Python驱动；FastAPI提供22个接口。
- 保留实体、独立事实、证据、来源、尺寸、推测性质、审核状态及模型映射；直接图关系由事实派生。
- 内部鉴权、增量变更集、完整校验、事务提交、重复请求保护、版本冲突和历史追踪。
- 可恢复删除及内部回收站；删除前检查引用，恢复事实／模型映射后重新审核。
- 公众／内部图谱展示和关系筛选，数据库版检查页已连接后端；页面仍为只读浏览，维护通过内部API。
- Docker镜像摘要及Python依赖锁定、独立测试容器、启动及接口文档。

完整知识含128实体、423事实，其中233条实体关系、54项尺寸；72段证据、7个来源、7组候选模型映射。所有事实仍待审核。公众候选投影87节点、76条展示关系；默认隐藏孤立节点时实际绘制63节点。公众投影不等于内部全量。

## 队友如何接入

先按[后端启动说明](../backend.md)准备Python虚拟环境及Docker，再生成本机配置、启动数据库并导入已有基线，最后运行API。首次配置脚本生成独立密码和操作员凭据，不需要复制开发者本机配置。

本机图谱入口`http://127.0.0.1:8780/`，接口交互文档`http://127.0.0.1:8780/docs`，OpenAPI JSON为`/openapi.json`。这些地址指各自电脑，不能作为其他队员直接访问开发者电脑的共享网址。

- 展示公众图谱：GET`/api/v1/graph`，注意truncated及服务端发布模式。
- 读取内部完整知识：鉴权GET`/api/v1/internal/snapshot`。
- 复用检查页数据：鉴权GET`/api/v1/internal/inspector`；普通公众版为`/api/v1/inspector`。
- 前端使用entities作为节点，有object_id的facts作为边；value事实作为属性／描述，通过evidence_ids及source_id追溯依据。
- 新增、修改、审核、删除与恢复：内部change-sets创建→validate→commit，详见[删除与恢复](../deletion.md)。

浏览器只请求API，数据库凭据保留服务端。正式公众模式为confirmed_only，本机课堂配置显式启用candidate_preview并标明候选状态。跨源前端接入前应安排同源代理。
