- 汇编中的箭头链未用作安装顺序；第 6 页下部示意图也未转写为主展品的受力/性能结论。

- 候选中的 `source_checked` 是 Agent 在本地查看页面后的对应检查，不表示已完成组员复核；所有事实为 `pending`。

## 模型结构初查

`data/scenes/model-inspection.json` 记录完整命名节点索引、重名和动画元数据：709 个节点、633 个 mesh、3 段动画。动画名为“行进与轮轴运动”“部件拼装”“拆解与复位”。
