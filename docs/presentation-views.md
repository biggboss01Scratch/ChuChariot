# 公众图谱与内部核对视图

2026-11-23。本轮只增加展示投影和关系筛选，知识数据仍为v0.11、本体仍为v0.7，原JSON不变。这里的公众／内部是本地预览用途，不是用户身份授权。

## 入口及筛选

- 公众预览：`http://127.0.0.1:8770/?audience=public`
- 内部核对：`http://127.0.0.1:8770/?audience=internal`

页面默认公众预览。展示用途和“候选检查／已确认知识”分别控制：公众预览不会自动确认知识，仍保留待复核与推测标注。当前正式确认数为零，候选预览不等于最终发布。

| 关系组 | 公众预览 | 内部核对 |
| --- | --- | --- |
| 结构与连接 | 可勾选 | 可勾选 |
| 材质与外观 | 可勾选 | 可勾选 |
| 复原示意与案例 | 可勾选，保留推断／假设性质 | 可勾选 |
| 分类与教学栏目 | 隐藏 | 可勾选 |
| 资料与语境词义 | 隐藏 | 可勾选 |
| 路径与模型元数据 | 隐藏 | 可勾选 |
| 未归类的新关系 | 默认隐藏 | 归入其他内部关系 |

公众节点隐藏教学栏目、路径说明、依据类别、模型版本和词义管理节点。普通来源目录不进入公众主图；六项现代复原案例保留，相关边显示“复原案例涉及”，不提升案例中推测的性质。

当前内部视图保留128实体、423事实、233条关系；公众投影为87个目录实体、209条可预览事实、76条关系、43项尺寸、47段证据。默认隐藏无连线节点，公众主图通常为63节点，随选择与筛选变化。数量减少是投影结果，不是删除知识。

关系勾选只改变绘图，属性、来源、页码、视频时间及推测理由仍可查看。“隐藏无连线节点”默认在公众模式开启，内部模式关闭。模型映射管理页只在内部模式显示。

## 接口及边界

`GET /api/preview?review=1&audience=public`返回公众投影，`audience=internal`返回完整核对视图。省略audience仍按旧接口返回内部视图；未知或重复audience返回400。

服务端规则位于`chuchariot/presentation.py`。证据和来源随事实保留，未知关系默认内部；公众布局提示仅含浏览分区，不返回隐藏分类边。前端依照响应中的关系组勾选。旧服务不支持公众投影时提示重启，不静默显示完整内部数据。

本工具仍只在本机回环地址运行，允许开发者切换两种用途，没有登录与角色鉴权。**展示开关不等于“只有内部人员才能访问”。**正式对外部署时，应给内部页面及接口增加服务端鉴权，或将公众服务固定为公众投影、单独部署内部工作台，不能只隐藏按钮。

## 验证

105项Python和16项Node测试通过，覆盖内部完整性、公众管理节点和边移除、推测及出处不变、审核独立、未知关系默认内部、媒体和布局引用、关系勾选保留属性。
